# 画像の指示書（会話Q：サクラダ銀行の背景。人物なし。10枚）

## 目的と使い方

この1ファイル＝ Gemini の新しい会話1つ分です（10枚。必須9、任意1）。**人物なしの背景だけ**を作ります。
指示文は上から順に1つずつ貼ってください。毎回アキヒロの基準画像（akihiro_base_v2.png）を、画風の参考として添付します（人物は描かせません）。人物の基準画像は添付しません。同じ場所の絵は、先に作った背景を添付して「変更だけ加える」形にして、建物・家具の形をそろえます。
元の全体版：image_prompts.md

### なぜ背景だけか
台本の会話ショットは、背景（ぼかした場面の絵）の後ろに、立ち絵（緑の背景を抜いたバストアップ）を重ねる。場面の絵に人物が入っていると、ぼかした背景の中に同じ人物がもう一度写り、Gemini が描く人物は立ち絵と顔や服がずれる。そこで、**場面の絵は背景だけ**にし、場面ショットも「背景＋立ち絵（表情・老け差分つき）」で作る。辞令・表彰状・ノートパソコン・付せん・通知・手引き・受話器など、人が持つ物はエンジンで描く（背景には描かない）。

### 背景の画像の作り方（共通）
- 人物は描かない。通行人・お客さんは、行列（R4）と困るお客さん（R9）の2か所だけ。**遠くに小さく、顔を描かない単純な人影**にして、主要人物と見分けがつくようにする。ぼかした背景にしたとき邪魔にならないよう、画面の左右の端に寄せる。
- 画面の下半分の中央〜左右は、人が立つ余白（床だけ）。目線の高さは立った人の胸〜目の高さ。立ち絵のバストアップを下半分の中央に重ねられる。
- 場所に付いているもの（無地のホワイトボード、無地の大画面・モニター、窓口の端末、壇・演台）だけを描く。画面・付せん・書類は無地。

## 生成の順番と手順
1. **【画風の確認】会話Kで、偉い人の基準画像（1-1）を2〜3案作り、1枚選ぶ。この1枚だけを、ZIP にせず画像のままアップロードして確認をもらう。OK が出るまで、ほかの画像は作らない**（画風がずれていたら、ここで直せば全部のやり直しを避けられる）。
2. OK が出たら、同じ会話Kで偉い人の差分を作る。続けて会話L・M・N・Oで行員A・B・C・窓口の先輩の基準画像（2〜3案から1枚）と差分を作る。
3. 寓話の断面図は構造が難しいので、**会話Pで F1 と F2 を作った時点で、画像のままアップロードして確認をもらう**（3本の別々の柱、地層の違い、「AI」の文字が出ているか）。OK が出てから F3 以降を作る。
4. サクラダ銀行の場面（会話Q）と、F6・F7（会話S）を作る。会話ごとに1つの ZIP でアップロードする（どの会話の ZIP かだけ添える）。
5. 受け取ったら制作側が `intake.py` で保存名を付け、背景を抜き、位置をそろえて動かして確かめる。
