# 画像生成指示書：スコップを渡された人たち（コミカル版）

シリーズ共通の語り手アキヒロの差分は `video/characters/akihiro/image_prompts.md`（コミカル版に書き直し済み）。この指示書は、この回の立ち絵（偉い人・行員A・B・C）と場面イラストの指示書。

保存先：`video/assets/images/shovel/`（リポジトリには入れない）。写実版の画像（`*_v1`）は使わない。コミカル版は**立ち絵は `_v2`、辞令の場面も `_v2`、ほかの場面は `_v1`** から始め、作り直すたびに番号を上げる（`video/STYLE.md` のファイル名のルール）。

**あなた（人）にお願いする作業は「生成して、ZIP でアップロードする」だけです。** ファイル名は制作側が付けます（人は名前を付けなくてよい）。緑の背景を抜く、切り抜き、サイズや位置の補正、差分の重ね合わせ確認も制作側が行います。

## 目的と使い方（どの場面でどう動かすか）
- **立ち絵**：会話ショットで並べ、話している人物だけを揺らす。口は台詞の音量に合わせて「閉じ（基準画像）／半開き／開き」を、**口のまわりだけ**重ねて切り替える（`core.Tachie`）。表情は台本の声の調子に合わせて、表情ごとの基準画像に差し替える。
- **場面イラスト**：場面ショットで大きく見せ、ゆっくり拡大・移動する。文字（地層の名前、碑銘、年月、ボードの文字など）は動画側で重ねる。
- 全員、アキヒロの基準画像と同じ簡単さ（太い均一な黒線、平塗り、影なし、丸く大きな顔、点の黒目）にそろえる。見本の穴の場面（`style_1_dig_v1.png`）より描き込みを減らす。

## Gemini の設定（モデル・思考レベル・何案作るか）
- モデル：「日々の暮らしをサポート（4 Hydrogen）」。思考レベル：標準。基準画像がなかなか決まらないときだけ「高」を試す。（試した結果わかったことは、ここに書き足す。いまのところ追記なし。）
- **基準画像（偉い人、行員A・B・C）は2〜3案作って1枚選ぶ。** 差分と場面イラストは1案で始め、気に入らないものだけ作り直す（場面イラストは構図が難しいので2案まで）。
- **会話の分け方**（差分は基準画像を添付した同じ会話で作るため）：
  - 会話K：偉い人（基準画像→差分）
  - 会話L：行員A　　会話M：行員B　　会話N：行員C
  - 会話P：穴の場面（N2→N13→N5→N6→N7→N8→N9→N10 の順。前の画像を添付してそろえる）
  - 会話Q：穴以外の場面（辞令→N1→N3→N12→N4→N11）
- 選んだ画像は、Gemini の画面からダウンロードして PC に置き、別の会話で添付するときはそのファイルを使う（名前は変えない）。

## 生成の順番と手順
1. **【画風の確認】会話Kで、偉い人の基準画像（1-1）を2〜3案作り、1枚選ぶ。この1枚だけを、ZIP にせず画像のままアップロードして確認をもらう。OK が出るまで、ほかの画像は作らない**（画風がずれていたら、ここで直せば全部のやり直しを避けられる）。
2. OK が出たら、同じ会話Kで偉い人の差分を作る（1-2〜1-6）。続けて会話L・M・Nで行員A・B・C の基準画像（2〜3案から1枚）と差分を作る。各会話の最後に ZIP を作らせる（各会話の末尾の指示文）。
3. 穴の場面は構造が難しいので、**会話Pで最初の N2 を作った時点でも、画像のままアップロードして確認をもらう**（3本の別々の柱、地層の違いが出ているか）。OK が出てから N13 以降を作る。
4. 辞令・N1・N3・N12・N4・N11（会話Q）を作る。立ち絵を作った会話の ZIP と、場面の会話の ZIP を、まとめてアップロードする（会話ごとに1つの ZIP でよい。どの会話の ZIP かだけ添える）。
5. 受け取ったら制作側が `intake.py` で保存名を付け、背景を抜き、位置をそろえて動かして確かめる。
