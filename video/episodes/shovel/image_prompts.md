# 画像生成指示書：スコップを渡された人たち（コミカル版）

シリーズ共通の語り手アキヒロの差分は `video/characters/akihiro/image_prompts.md`。この指示書は、この回の立ち絵（偉い人・行員A・B・C・窓口の先輩）と場面イラストの指示書。

保存先：`video/assets/images/shovel/`（リポジトリには入れない）。**立ち絵は `_v2` から**（写実版の `shovel_*_base_v1.png` などが同じ名前で残っているため、番号を上げて区別する。写実版は使わない）。場面イラストは企画書の名前（`shovel_real_*`、`shovel_fable_*`）の `_v1` から。作り直すたびに番号を上げる（`video/STYLE.md` のファイル名のルール）。

**あなた（人）にお願いする作業は「生成して、アップロードする」だけです。**（ZIP にまとめる指示は、あなたが Gemini に出します） ファイル名は制作側が付けます。緑の背景を抜く、切り抜き、サイズや位置の補正、差分の重ね合わせ確認も制作側が行います。

## 目的と使い方（どの場面でどう動かすか）
- **立ち絵**：会話ショットで並べ、話している人物だけを揺らす。口は台詞の音量に合わせて「閉じ（基準画像）／半開き／開き」を、**口のまわりだけ**重ねて切り替える（`core.Tachie`）。表情は台本の声の調子に合わせて、表情ごとの基準画像に差し替える。窓口の先輩も、画面で話す場面が増えたので立ち絵を作る。
- **場面イラスト**：場面ショットで大きく見せ、ゆっくり拡大・移動する。文字（銀行名、看板、パソコンや大画面の表示、付せんの中身、年月、層の名前、碑銘）はすべて動画側で重ねる。
- **構成が2つに分かれる**：寸劇（サクラダ銀行の現実の職場。旧 R1〜R11 は人物なしの背景）にはスコップ・穴・碑を出さない。スコップの寓話（解説 E4）は別の絵（F1〜F5）で、**スコップの刃の赤い「AI」だけ**を画像に描かせる。
- 全員、アキヒロの基準画像と同じ簡単さ（太い均一な黒線、平塗り、影なし、丸く大きな顔、点の黒目）にそろえる。
- 台本の台詞は、この指示書には書かない（台詞は変わることがあるため）。表情と構図だけを指定する。

## Gemini の設定（モデル・思考レベル・何案作るか）
- モデル：「日々の暮らしをサポート（4 Hydrogen）」。思考レベル：標準。基準画像がなかなか決まらないときだけ「高」を試す。（試した結果わかったことは、ここに書き足す。いまのところ追記なし。）
- **基準画像（偉い人、行員A・B・C、窓口の先輩）は2〜3案作って1枚選ぶ。** 差分と場面イラストは1案で始め、気に入らないものだけ作り直す（場面イラストは構図が難しいので2案まで）。
- **会話の分け方**（差分は基準画像を添付した同じ会話で作るため）：
  - 会話K：偉い人　会話L：行員A　会話M：行員B　会話N：行員C　会話O：窓口の先輩（それぞれ基準画像→差分）
  - 会話P：寓話の断面図（F1→F2→F3→F4→F5 の順。前の画像を添付してそろえる）
  - 会話Q：サクラダ銀行の背景（人物なし、10枚。事務室→プロジェクト室→同・付せん→本部の席→大画面→窓口（昼）→行列→数年後→壇→夜 の順）
  - 会話S：寓話のほかの場面（F6、F7）
- 選んだ画像は、Gemini の画面からダウンロードして PC に置き、別の会話で添付するときはそのファイルを使う（名前は変えない）。

## サクラダ銀行の場面（R1〜R11）の共通ルール
- 銀行名は「サクラダ銀行」だが、**名前以外のヒントを重ねない**（企画書「サクラダ銀行で重ねないもの」）。看板・ロゴ・名札に銀行名の文字は描かせない（動画側で重ねる）。
- 指示文に毎回入れている見た目の指定：
```
【サクラダ銀行の見た目（銀行の場面すべてで共通）】架空の銀行。壁と床は、クリーム色・黄みのグレージュ（灰色）・薄い木の色。カウンターや机は薄い木の色と白。**青を基調にした配色、青い制服、青い看板は使わない**（どの実在の銀行の色にも寄せない）。ロゴや看板に当たる部分は、文字を描かず、濃いグレーの丸の中に、からし色の四角がひとつ入った、文字のない単純な図形（壁に小さく付ける程度）。桜の花、教会・塔・建設中の建物・足場を思わせる形は描かない。行員の服は人ごとに違う色のままにして、制服のように統一しない。
```

## 生成の順番と手順
1. **【画風の確認】会話Kで、偉い人の基準画像（1-1）を2〜3案作り、1枚選ぶ。この1枚だけを、ZIP にせず画像のままアップロードして確認をもらう。OK が出るまで、ほかの画像は作らない**（画風がずれていたら、ここで直せば全部のやり直しを避けられる）。
2. OK が出たら、同じ会話Kで偉い人の差分を作る。続けて会話L・M・N・Oで行員A・B・C・窓口の先輩の基準画像（2〜3案から1枚）と差分を作る。
3. 寓話の断面図は構造が難しいので、**会話Pで F1 と F2 を作った時点で、画像のままアップロードして確認をもらう**（3本の別々の柱、地層の違い、「AI」の文字が出ているか）。OK が出てから F3 以降を作る。
4. サクラダ銀行の場面（会話Q）と、F6・F7（会話S）を作る。会話ごとに1つの ZIP でアップロードする（どの会話の ZIP かだけ添える）。
5. 受け取ったら制作側が `intake.py` で保存名を付け、背景を抜き、位置をそろえて動かして確かめる。
