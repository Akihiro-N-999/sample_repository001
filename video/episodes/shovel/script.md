# 台本：スコップを渡された人たち

- 企画：`plan.md`（G1 了承済み plan_v7）。場面は H0・K0〜K14・X・E1〜E10 の27場面。前の版の写しは `versions/script_v1.md`。
- 話者ID：`narr`（アキヒロ）、`boss`（偉い人）、`a`（行員A）、`b`（行員B）、`c`（行員C）、`senpai`（窓口の先輩。今回から立ち絵あり）。同時発話は `a+b+c`（3人の声を重ねる）。
- 「読み」欄は、書いたときは**その文全体**がそのまま読み上げに使われる（`voice_preview.py` は読み欄を台詞の代わりに読む）。読み間違えそうな語だけかなにしている。文頭の「……」は読み欄で外している。
- 「声の調子」の欄には、characters.md の調子別IDのキーワード（偉い人：熱血・焦り・喜び・困り、行員A：驚き・困り・焦り・喜び・張り切り）を1つだけ入れている（2つ入れると先に見つかったほうになるため）。
- 画像に描かせる文字はスコップの刃の赤い「AI」だけ（解説の寓話 E4 と答え E9 だけに出る）。演出欄にある文字（銀行名、看板、画面の表示、AIエージェントの答え、付せん、カード、年月）はすべて動画側で重ねる。

### 寸劇の決まりごと
- **銀行名の定義：「サクラダ銀行」**（読み：さくらだぎんこう）。台詞で言うのは #3 の1か所だけ、画面の文字は K1 の看板（#5 の演出）の1か所だけ。名前を差し替えるときは、この2か所とここを直す。
- 「※この物語はフィクションです」は H0 と K0 の画面の下に小さく出し（読み上げない）、K1〜K14 のあいだも画面の右下にごく小さく出し続ける。「数年後（作者の想像）」は左上に出し、右下の表示と重ねない。寓話（E4）の「私に見えた物語（たとえ話）」は紙芝居の枠の隅に出す（寸劇の表示とは同時に出ない）。数年後の場面（H0 の #1・#2、K10 の終わり〜K14）は、隅に小さく「数年後（作者の想像）」を出す。
- 名前以外のヒントは重ねない：青い色・桜・教会や塔の図柄、システム障害・統合・停止・「完成しない」「延期」を思わせる台詞と小道具は入れない。AIエージェントは予定どおり完成して表彰され、数年後に答えが古くなる流れにする（壊れる・止まるにはしない）。数年後の画面の吹き出しも、赤い警告ではなく落ち着いた返答にする。
- 報道の数字（3か月、1年半、5人、4人、全員合格、20人、100人、数千人、5,000人分）と研修の名前は、寸劇で言わず画面にも出さない。研修や研修を受けた人を笑わない（研修は役に立ち、3人はちゃんと作り上げる）。
- 偉い人は悪人にしない（善意と勢いの楽天的な上司）。一般的な上司の口ぶりだけで話し、銀行の説明（「人を減らすのではない」「人を移す」「ノウハウを社内に残す」など）は言わない。
- 伏線の決まり文句は「奥の棚の、青いファイルの3ページ目です」（名義変更の書類の場所）。#22（教える）→ #30（電話で先輩を助ける）→ #45 の吹き出し（AIエージェントが一瞬で答える）→ #69・#72（数年後、AIエージェントも行員Aも同じ古い答えを返す）で、毎回同じ文言にする。
