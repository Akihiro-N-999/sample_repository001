# キャラクター設定：スコップを渡された人たち

企画：寸劇はサクラダ銀行の現実の職場の物語（スコップ・穴・碑は出さない）、解説の寓話（E4）でスコップの絵を見せる。画風はコミカル版（`video/STYLE.md`）。
全員、画像生成AI（Gemini）で作る立ち絵（緑背景、アキヒロと同じ構図）。コードで描く `person()` は使わない（確認用のキャラ表では「画像待ち」）。
画像の指示書：この回の人物は `video/episodes/shovel/image_prompts.md`、アキヒロは `video/characters/akihiro/image_prompts.md`。画像は `video/assets/images/shovel/`（アキヒロは `video/characters/akihiro/images/`）。写実版（`*_v1`）は使わない。コミカル版の立ち絵は `_v2` 以降。
台本は台本担当が書き直し中。口調・一人称は、旧台本（`script.md` の前の版）と内容校閲の指摘（`review_content.md`）に合わせた。**新しい台本が書き終わったら、台詞の口調・一人称が合っているか確かめて、この文書を直す**（印は「要確認」）。

- 性格：誠実で少し困ったような真顔。事実と意見を言い分ける。当事者を責めない。
- 口調：です・ます調。一人称「私」。よく言う言葉：「〜と思います」「〜かもしれません」「私に見えた物語です」。
- 立ち絵：`video/characters/akihiro/`（基準画像 `akihiro_base_v2.png` は作成済み。口・目・笑顔の差分は `video/characters/akihiro/image_prompts.md`）。黒髪の短髪、黒縁の四角い眼鏡、白い開襟シャツ。

## 偉い人（話者ID: boss）

- 性格：人のよさそうな押しの強い上司。声が大きく、調子がよく、先のことを考えていない。
- 口調：一般的な上司の標準語。一人称「私」。よく言う言葉：「今日から君たちは〜だ！」「なんとかなる！」「君たちはもうエンジニアだ！」。銀行の説明（「人を減らすのではない」「人を移す」など）や報道の数字は言わない。

## エンジンへの追加要望
- 口が3段階（閉じ・半開き・開き）の差分に対応してほしい。いまの `core.Tachie` は「基準画像＋口開き1枚」だけなので、半開きを足し、音量に応じて切り替える改修が必要（半開きの画像は必須として作る）。
- 表情ごとの基準画像（困り、張り切った笑顔、驚き、しょんぼり、得意げ、ほっとした笑顔など）に差し替え、表情ごとに口開き画像を持てるようにしてほしい（口のまわりだけ重ねる処理は、その表情の基準画像に対して行う。口開きを作らない表情は口パクなしで揺れだけ）。
- 老け差分（任意）や表情への差し替えを、台詞の途中で切り替えられるようにしてほしい。
- 目閉じ差分でのまばたきの自動化は、今回は目閉じを作らないので不要（アキヒロだけ `akihiro_eyes_closed_v2.png` を使う）。
- 窓口の先輩の電話の声（動画側でこもらせるフィルタ）。
