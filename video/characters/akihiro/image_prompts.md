# 画像生成指示書：語り手アキヒロの差分（コミカル版）

シリーズ共通の語り手「アキヒロ」（話者ID: narr、声は VOICEVOX 玄野武宏）。**コミカル版**（`video/STYLE.md`、2026-11-14 決定）の基準画像 `video/characters/akihiro/images/akihiro_base_v2.png` はすでにある。この指示書は、その基準画像から作る口・目・表情の差分と、サムネイル用画像。写実版の指示書は `versions/image_prompts_v1.md` に退避した（写実版は使わない）。

保存先：`video/characters/akihiro/images/`（リポジトリには入れない）。コミカル版の差分は基準画像に合わせて `_v2` から始め、作り直すたびに番号を上げる（`video/STYLE.md` のファイル名のルール）。

**あなた（人）にお願いする作業は「生成して、ZIP でアップロードする」だけです。** ファイル名は制作側が付けます。緑の背景を抜く、サイズや位置の補正、差分の重ね合わせ確認も制作側が行います。

## 目的と使い方（どの場面でどう動かすか）
- 寸劇では、アキヒロは声だけ（K0・K1・K3・K6・K7・K15 の語り）か、画面の端の小さな立ち絵。解説（X・E1〜E8、約2分30秒）では、立ち絵が大きく出て話し続ける。口は台詞の音量に合わせて「閉じ（基準画像）／半開き／開き」を口のまわりだけ重ねて切り替え、目はときどき閉じてまばたきする。
- 笑顔は E8（前向きな締め）で使う。困り・驚きの表情は今回の台本では使わない予定なので、台本で必要になってから作る（作るときは下の「表情の差分の作り方」と同じ型で、基準画像を添付して眉・目・口だけを変える）。

## Gemini の設定（モデル・思考レベル・何案作るか）
- モデル：「日々の暮らしをサポート（4 Hydrogen）」、思考レベル：標準。
- 差分は1案で始め、基準画像と位置・大きさがずれた画像だけ作り直す。サムネイルは2案まで。
- **新しい会話**で、毎回 `akihiro_base_v2.png` を添付して始める（添付した画像が編集する画像であり、画風の参考でもある）。続けて作る差分は同じ会話でよい。
- 試した結果わかったことは、ここに書き足す（いまのところ追記なし）。

## 生成の順番と手順
1. 新しい会話を開き、`akihiro_base_v2.png` を添付して、1-1 → 1-2 → 1-3 の順に作る。
2. 続けて 2-1 → 2-2（あとで）、3（任意）。
3. 会話の最後に、ZIP を作らせる指示文（下）を貼る。Gemini が ZIP を作れなかったときは、予備の方法（下）で。
4. ZIP をアップロードする。受け取ったら制作側が `intake.py` で保存名を付け、背景を抜き、基準画像との位置合わせを確かめる。

## 受け取り後の確認項目（人が見て、作り直すか決める）
- 画風が基準画像と同じか（太くほぼ均一な黒線、平塗り、影なし、丸い顔、点の黒目）。
- 基準画像と、髪・眼鏡・服・輪郭・体の位置・大きさが同じか（変わってよいのは口・目・表情だけ）。眼鏡の形が変わっていないか。
- 背景が緑一色か。髪・眼鏡・服に緑が混ざっていないか。文字・ロゴ・記号が入っていないか。
- 口開きの口が、基準画像に重ねたときに不自然でない範囲か（確認は制作側）。

### 緑のにじみ対策（制作側から頼んだときだけ）

