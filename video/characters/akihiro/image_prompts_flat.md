# 画像生成指示書：アキヒロ（平塗りのやわらかい絵柄版）

## 目的と使い方
見本B（登場人物と背景に、外部のフリーイラスト素材を並べて使う方式）用の、語り手アキヒロの別絵柄。
アキヒロだけは本人なので、素材の人物の隣に置いても浮かないよう、**シンプルでやわらかい平塗りのイラスト**に作り直す。既存の `image_prompts.md`（写実寄りの漫画絵柄）とは別物で、見本Bでだけ使う。
動画では、台詞に合わせて口を切り替え（閉じ／開き）、ときどき目を閉じる（まばたき）。

保存先: `video/characters/akihiro/images/`（リポジトリには入れない）

**あなた（人）にお願いする作業は「生成して、ダウンロードしたまま（名前は変えずに）1つのフォルダに入れて ZIP にし、アップロードする」だけです。ファイル名は制作側で付けます（下の表の名前、`_v1` から始めて作り直すたびに番号を上げる）。** 緑の背景を抜く、サイズや位置の補正、差分の重ね合わせ確認は制作側で行います。

## 優先順位
| 優先 | 画像 |
|---|---|
| **必須** | 1. 基準画像、2-1 口開き、2-2 目閉じ（計3枚） |
| あとで・任意 | 口半開き、表情差分（見本では作らない） |

## Gemini の設定
- モデル：「日々の暮らしをサポート（4 Hydrogen）」、思考レベル「標準」。
- **基準画像は2〜3案作って1枚を選ぶ。** 差分は基準画像を添付し、気に入らなければその1枚だけ作り直す。
- 基準画像は、前に基準画像を作った会話の続きでも、新しい会話でもよい。新しい会話なら、手順1で顔立ちの参考画像を添付する。差分（手順2）は**必ず基準画像を添付した同じ会話の中**で頼む。

## 共通スタイル指定（すべての指示文の先頭にそのまま入れる。指示文の中に記載済み）
```
シンプルでやわらかい平塗りのイラストにしてください。輪郭線は細めで太さが均一な、濃い茶色がかった黒の線。塗りは淡くやさしい単色のべた塗りで、影、ハッチング（斜線）、グラデーション、ハイライトは入れない。体型は丸みのある頭身低めの人物（2.5頭身から3頭身）。目は小さな黒い点、鼻はごく小さな短い線か省略、口は小さな線で表す。手足は単純な形にする。リアルな質感や劇画調の彫りは入れない。
```

## 生成の順番と手順
1. 手順1で基準画像を作る（2〜3案から1枚選ぶ）。
2. 選んだ基準画像を添付し、同じ会話で 2-1、2-2 を作る。
3. 3枚をダウンロードしたまま1つのフォルダに入れ、ZIP にしてアップロードする。

## 指示文（1枚ずつ）

### 1. 基準画像（全身・正面・口閉じ）
- ファイル名: `akihiro_flat_base_v1.png`
- 添付: `video/characters/akihiro/images/akihiro_base_v1.jpg`（顔立ち・髪型・眼鏡・服の特徴の参考としてだけ。絵柄は真似しない）
- 縦横比: 2:3（縦長）

```
シンプルでやわらかい平塗りのイラストにしてください。輪郭線は細めで太さが均一な、濃い茶色がかった黒の線。塗りは淡くやさしい単色のべた塗りで、影、ハッチング（斜線）、グラデーション、ハイライトは入れない。体型は丸みのある頭身低めの人物（2.5頭身から3頭身）。目は小さな黒い点、鼻はごく小さな短い線か省略、口は小さな線で表す。手足は単純な形にする。リアルな質感や劇画調の彫りは入れない。

添付した画像の男性の特徴（黒い短髪、黒縁の四角い眼鏡、白い開襟シャツ、30〜40代の日本人男性）だけを参考にして、上の絵柄で、同じ人物の「全身の立ち絵」を新しく描いてください。添付画像の絵柄（濃い主線、斜線の陰影、写実的な顔）は真似せず、背景と文字は無視してください。

【構図】
- 縦長 2:3。全身を、頭からくつの先まで描く。体も顔も正面向き、目線はこちらを見る。腕は体の横に自然に下ろし、足は肩幅より少し狭く開いて、まっすぐ立つ。
- 人物は画面中央に置き、頭の上、足の下、左右に少し余白を残す。体の一部が画面の端で切れないようにする。

【人物】
- 黒の短髪。前髪は額にかかる。髪は黒のべた塗りで、毛先の流れを数本の簡単な線だけで表す。
- 黒縁の四角い眼鏡。細い線で描き、レンズは透明（肌色が見える）。レンズの中に小さな黒い点の目が見える。
- 眉は短い線で、少しだけ寄せる（誠実で、少し困ったような真顔）。
- 口は閉じる。小さな水平の短い線。
- 白い開襟シャツ（第一ボタンは開け、襟は少し立つ。ボタンは小さな点でよい）。シャツは白のべた塗りで、輪郭線で形をはっきり見せる。
- 下は、落ち着いた濃い灰色の無地のズボンと、黒いくつ。
- 肌は、淡いやさしいベージュのべた塗り。
- 首や胸にストラップ、名札、アクセサリーはつけない。

【背景】
- 緑一色（#00FF00）のべた塗りだけ。影、地面、床、グラデーション、模様、枠線は描かない。足元の影も描かない。
- 人物の輪郭の外側に、緑以外の色のにじみやぼかしを出さない。輪郭は途切れない線で閉じる。人物に緑色を使わない。

【禁止】
- 画像の中に、文字、ロゴ、看板、記号、透かしを入れない。
- 既存の作品やキャラクターに似せない。
```

```

- 口を開けて「あ」と話している形にする。小さな丸みのある開いた口で、中は暗い赤茶色のべた塗り。歯や舌は描かない。絵柄に合わせて単純な形にする。
- それ以外は一切変えない。構図、顔の位置、人物の大きさ、全身の位置、髪型、眼鏡、目、眉、輪郭、服、肌の色、線の太さ、塗り方、緑の背景、縦横比 2:3 は基準画像と同じにする。
```

## 受け取り後の確認項目（人が見て、作り直すか決める）
- 文字・ロゴ・名札・ストラップが入っている
- 背景が緑一色になっていない（足元の影、床、模様、グラデーションがある）
- 髪・服・肌に緑っぽい色が混ざっている
- 影、斜線、グラデーションが入っていて、平塗りになっていない
- 眼鏡・黒髪・白シャツの特徴が残っていない（基準画像の人物に見えない）
- 全身が画面内に収まっていない（足が切れている）
- 口開き・目閉じで、口や目以外（髪、服、位置、大きさ）が基準画像と変わっている

制作側で、輪郭の外側に緑のにじみが残るときは、次の作り直しを頼むことがある。
```
添付した画像と同じ画像で、人物の輪郭の外側の背景を、緑ではなく純粋な白（#FFFFFF）のべた塗りに変えてください。人物は一切変えないでください。
```

## 内容校閲への申し送り
- 元画像：ユーザー本人の自撮り写真から、ユーザーが Gemini で作ったイラスト（顔立ちの参考にだけ使う）。本人なので肖像の問題はない。
- 絵柄は言葉（細い均一な輪郭線、淡いべた塗り、陰影なし、頭身低め、点の目）だけで指定し、特定のサイトや作者、作品の名前は指示文に入れていない。生成結果が特定の素材サイトの絵に酷似していないか確かめてほしい。
- 見本Bでは、別途フリーイラスト素材を人物と背景に使う。その素材の利用規約（動画での使用、収益化、加工の可否）は別に確かめる必要がある。
- Gemini（Google AI Plus）の利用規約で、生成画像を YouTube で公開・収益化してよいかを公開前に確かめてほしい。
