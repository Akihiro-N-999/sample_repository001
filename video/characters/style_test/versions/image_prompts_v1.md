# 画像生成指示書：画風の見本（コミカル寄り2案（候補1・候補3））

## 目的と使い方（どの場面でどう動かすか）
寸劇の内容がコミカルな誇張なのに、今の写実寄りの画風（`akihiro_base_v1.jpg` など）だと重く見える。そこで、もっとコミカルな画風を2案（候補1と候補3）、同じ題材で1案2枚ずつ作って見比べ、シリーズの画風（`video/STYLE.md`）を決め直すための**見本**を作る。見本は動画には使わない。決まった画風で、あらためて本番の指示書を作る。

作る見本（計4枚）:
| 候補 | 画風 | アキヒロ（立ち絵） | 穴を掘る場面 |
|---|---|---|---|
| 1 | 4コマ風（太い均一な線・平塗り） | `style_1_akihiro_v1.png` | `style_1_dig_v1.png` |
| 3 | 今の画風を崩した版（5〜6頭身） | `style_3_akihiro_v1.png` | `style_3_dig_v1.png` |

保存先: `video/assets/images/style_test/`（リポジトリには入れない）。

**あなた（人）にお願いする作業は「生成して、ダウンロードしたまま（名前は変えずに）1つのフォルダに入れて ZIP にし、アップロードする」だけです。** ファイル名は制作側で付けます。どの候補のどの画像かは、絵（アキヒロの絵柄、穴の場面の線の太さ・頭身）で見分けます。背景の緑を抜く作業なども制作側で行います。

## 優先順位（必須／あとで／任意）
- **必須**：4枚すべて（比べるのが目的なので、1案でも欠けると比べられない）。
- あとで／任意：なし。見本が決まるまで、口差分・表情差分は作らない。
- 1案あたり、アキヒロ→穴の場面の順に作る。候補1→候補3の順に作る。

## Gemini の設定（モデル・思考レベル・何案作るか）
- モデル：「日々の暮らしをサポート（4 Hydrogen）」。思考レベル：標準。
- **候補1と候補3は、それぞれ別の Gemini の会話（新しいチャット）で作る。** 同じ会話で続けると画風が混ざる。
- 1つの候補の中は**同じ会話**で、アキヒロ→穴の場面の順に作る（穴の場面にはアキヒロの見本を画風の参考として添付するため）。
- 見本なので、各画像は1〜2案作って気に入った1枚を選べばよい。アキヒロ（立ち絵）で絵柄が大きく外れたら、そこで作り直してから穴の場面へ進む。

## 共通の守ること（すべての指示文に入っている。変えない）
- 画像の中に、文字・ロゴ・看板・社名・名札の文字・透かしを入れない。**例外：スコップの刃にだけ、赤い太字で「AI」の2文字**（どの画像でも同じ書き方）。
- 既存の作品の登場物（乗り物、メカ、衣装、キャラクター）を入れない。
- 実在の人物や企業を思わせる見た目にしない。
- アキヒロの特徴（3案とも残す）：30〜40代の日本人男性、黒髪の短髪、黒縁の四角い眼鏡、白い開襟シャツ（第一ボタンは開ける）。首にはなにも掛けない。

## 画風指定（候補ごと。その候補のすべての指示文の先頭にそのまま入れる）

### 画風1：4コマ風
```
【画風】コミカルな4コマ漫画のイラスト。輪郭線は太い黒線で、太さはほぼ均一（強弱をつけない。画面の高さの約0.7%の太さ）。内側の線（服のしわ、髪の筋）も同じ太さで、数は少なく単純にする。ハッチング（斜線）や影は描かない。塗りは、はっきりした明るい色の平塗り（影は付けない）。頭身は4頭身前後で、頭と顔が大きく丸く、体と手足は丸みのある単純な形。目は小さめの黒い点のような黒目。表情は大げさ：驚きや焦りでは口を顔の三分の一ほど大きく開け、眉は八の字にする。漫符を使う（汗のしずく、怒りマーク、驚きの放射線、青ざめた縦線）。色調は明るく彩度は高め、白を多く残す。光源は決めず、全体を均一に明るく見せる。
```

### 画風3：今の画風を崩した版
```
【画風】大人向けの漫画イラストの質感を残しつつ、コミカルに崩す。輪郭線は黒い主線で、強弱をはっきりつける（外側の輪郭は太く、顔の内側や服のしわは細く。画面の高さの約0.3〜0.8%）。ハッチング（細い斜線）は残すが、量を今の半分以下に減らし、影の濃い所（首の下、服のたたみ、穴の奥）だけに使う。陰影は控えめ。頭身は5〜6頭身に少し下げ、顔の彫りは浅くして親しみやすくする。表情と身ぶりは大きく誇張する：眉を大きく上下させ、目を大きく見開き（白目が見える）、口は顔の四分の一ほど開く。体は大きく傾け、手足の動きも大きくする。漫符は控えめに使う（汗のしずく、驚きの短い放射線を少し）。塗りは落ち着いた質感だが、今より明るめで彩度をやや上げる。光源は左上からのやわらかい光。
```

## 生成の順番と手順（候補ごとに繰り返す）
1. **新しい会話**を開く（候補ごとに必ず新しく）。
2. 手順A：アキヒロの見本を作る。添付：今の基準画像 `akihiro_base_v1.jpg`（顔立ちの参考）。候補1だけ、さらに4コマ画像も添付する。
3. 手順B：**同じ会話の中で**、穴を掘る場面を作る。添付：手順Aで選んだアキヒロの見本（画風の参考）。候補1だけ、さらに4コマ画像も添付する。
4. 画像はダウンロードしたまま（名前は変えずに）フォルダに入れる。2候補ぶんをまとめて1つの ZIP にしてアップロードする。

## 指示文（1枚ずつ。添付する画像・指示文・保存するファイル名）
以下の `{画風}` の部分には、上の「画風指定」の該当する候補のブロックを**そのまま**貼る（先頭に置く）。

### 手順A：アキヒロの立ち絵（2候補共通の文、画風だけ入れ替える）
- 保存名：候補1 `style_1_akihiro_v1.png`／候補3 `style_3_akihiro_v1.png`
- 縦横比：3:4
- 添付：`akihiro_base_v1.jpg`（今の基準画像、顔立ち・髪型・眼鏡の参考）。**候補1のみ**、4コマ画像も添付し、末尾の一文を足す（下記）。
- 指示文：
```
{画風}

添付した1枚目の画像の人物（顔立ち・髪型・眼鏡・服の特徴）を、上の画風で描き直してください。背景や文字は参考にしないでください。

【人物】30〜40代の日本人男性、語り手。黒髪の短髪（前髪は額にかかり、毛先は少しはねる）。黒縁の四角い眼鏡。白い開襟シャツ（第一ボタンは開ける）。首にはなにも掛けない。きりっとした表情の基準は残すが、画風に合わせて親しみやすくデフォルメする。

【構図】バストアップ（胸から上）。正面向き。口は閉じる。目は開けて正面を見る。人物は画面の中央、頭の上に少し余白。

【背景】無地の緑一色（#00FF00）。影・グラデーション・床・枠線・模様を入れない。髪・服・眼鏡に緑を使わない。

【入れてはいけないもの】文字、ロゴ、看板、名札、透かし、既存の作品の登場物。
```
- 候補1のみ末尾に足す一文：`2枚目の画像（4コマ漫画）の絵柄（線の太さ、平塗り、丸みのある顔、小さな黒目）を、画風の見本としてそろえてください。ただし2枚目の人物や文字は描かないでください。`

### 手順B：穴を掘る場面（2候補共通の文、画風だけ入れ替える）
- 保存名：候補1 `style_1_dig_v1.png`／候補3 `style_3_dig_v1.png`
- 縦横比：16:9
- 添付：手順Aで選んだアキヒロの見本（**同じ会話の中の画像**。画風の参考）。**候補1のみ**、4コマ画像も添付する。
- 指示文：
```
{画風}

添付した画像と同じ画風・同じ線の太さ・同じ色の塗り方・同じ頭身で、次の場面を描いてください。添付した画像の人物は登場しません。画風だけをそろえてください。

【場面】広い野原のようなオフィスの外。横長の画面に、**地面の断面が見える3つの穴が横に並んで**いる。断面図のように、地面を縦に切って中が見えるようにする。地面の上（地表）は画面の上から約4割の高さ。

【3人の行員】3人は、それぞれ**自分の足元の穴**を、刃に赤い太字で「AI」と描かれたスコップで掘っている。3人とも、穴の中に腰まで（または胸まで）沈んでいる。右の人ほど深く沈んでいる。左から順に：
- 左：行員A。茶髪の若手男性。水色のシャツに濃いグレーのベスト。腰まで沈み、必死に掘って、額に汗のしずくが飛ぶ。
- 中央：行員B。黒髪をひとつ結びにした30代の女性。ネイビーのジャケット。胸まで沈み、青ざめた表情で、それでも掘る。
- 右：行員C。短い刈り上げの40代の男性。茶色のジャケット。首近くまで沈み、目を丸くして、あせって両手で掘る。

【スコップ】3人とも同じスコップ。刃に赤い太字で「AI」の2文字だけを描く（「Al」や「A1」にならないよう、アルファベットの大文字のAとIにする）。柄は木の色、刃は灰色。

【地層】それぞれの穴の断面に、色の違う地層が何層も重なっている（茶、黄土色、灰色、赤茶、薄緑がかった灰色など。人ごとに色の並びを変える）。それぞれの人が積み上げてきた経験の層を表す。地層に文字や模様の文字は描かない。

【知識の塊】3人はそれぞれ、掘り出した「知識の塊」を両手で上に差し出している。塊は、光る石、または書類が固まったような塊。ほんのり光らせる。

【偉い人】3つの穴の後ろ、地表に立つ上司（偉い人）。にこにこした笑顔。黒髪をなでつけた50代の男性。紺のスーツ、赤いネクタイ。両手を広げて、差し出された塊を受け取っている。足元には受け取った塊が小さな山になっている。上司の体は3人より少し大きく描く。

【背景】空は明るい水色、遠くに低い木と丘。単純にする。

【入れてはいけないもの】スコップの「AI」以外の文字、看板、ロゴ、社名、名札の文字、透かし、既存の作品の登場物。
```
- 候補1のみ末尾に足す一文：`もう1枚の4コマ漫画の絵柄（線の太さ、平塗り、丸みのある顔、小さな黒目、漫符）も、画風の見本としてそろえてください。ただし4コマの人物や文字は描かないでください。`

## 受け取り後の確認項目（人が見て、作り直すか決める）
- 2候補の画風が、指定どおりに違って見えるか（候補1は線が太く均一で平塗り・4頭身前後、候補3は強弱のある線とハッチングが残り5〜6頭身）。
- 候補ごとに、アキヒロと穴の場面の画風（線・塗り・頭身）がそろっているか。
- アキヒロ：黒髪、黒縁の四角い眼鏡、白い開襟シャツが残っているか。背景が緑一色で、髪や眼鏡に緑が混ざっていないか。口は閉じているか。
- 穴の場面：3人が別々の穴に沈んでいるか、右ほど深いか。地層が色違いで見えるか。上司が塊を受け取っているか。服・髪の指定どおりか。
- スコップの刃の赤い「AI」が崩れていないか（「Al」でないか）。それ以外の文字が入っていないか。
- 比べるときの観点：コミカルさが出ているか、見分けやすいか、台詞の場面で重く見えないか、動画の素材として長く見ても疲れないか。

## 内容校閲への申し送り（元画像の出どころ、気になる要素）
- 添付する元画像：今の基準画像（ユーザー本人から作った、語り手アキヒロの元イラスト。リポジトリ外）と、候補1のみ、ユーザーが Gemini で作った記事末尾の4コマ画像。どちらもユーザーが自分で生成したもの。
- 見本は画風比較のためだけに使い、動画には使わない。
- 画風は言葉だけで指定し、実在の漫画家・作品名は書いていない。生成画像が既存作品の絵柄・登場物に酷似していないか、文字・社名が混ざっていないかを確かめてほしい。
- 偉い人や行員は架空の人物。実在の人物や企業を思わせる要素が出ていないか確認してほしい。
