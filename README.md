# sample_repository001

複数のAIエージェントが協業して開発を進める「マルチエージェント開発フレームワーク」（Claude Code 用）。

## 使い方

Claude Code でこのリポジトリを開き、作りたい機能を渡す。

```
/develop CSVファイルを読み込んで月別の売上合計を出すコマンドを作って
```

オーケストレータ（メインセッション）が次の順にサブエージェントへ作業を割り振る。

```
設計 → コスト見積もり → 【設計監査】
  → テスト作成 ∥ 実装 → テスト実行（失敗なら修正ループ）
  → テスト結果まとめ ∥ ドキュメント ∥ 品質評価 → 【最終監査】 → 完了報告
```

【監査】で FAIL になると、指摘ごとに担当エージェントへ差し戻される（同じゲートで最大3回）。

## ファイル構成

| パス | 内容 |
|---|---|
| `CLAUDE.md` | フレームワーク全体のルールとプロジェクト設定（言語・テストコマンド） |
| `.claude/skills/develop/SKILL.md` | オーケストレータの手順（`/develop`） |
| `.claude/agents/*.md` | 9つのサブエージェントの定義 |
| `docs/policies/development-policy.md` | 敵対的監査がチェックする開発ポリシー |
| `docs/specs/<feature>/` | 機能ごとの設計・見積もり・テスト記録・監査結果 |

## カスタマイズ

- 守らせたいルールは `docs/policies/development-policy.md` に項目IDを付けて追加する。
- 担当を増やすときは `.claude/agents/` に定義を追加し、`develop/SKILL.md` の手順に呼び出しを足す。
