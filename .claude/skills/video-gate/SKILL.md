# ゲートの出し方

引数：ゲート名（G1〜G4）と slug。

1. **検査**：`python3 video/lib/gate_check.py <G1|G2|G3|G4> video/episodes/<slug>` を実行する。
   - [NG] があれば、担当に直させてから再実行する。直さないで出す場合は、NG の内容と理由をユーザーへのメッセージに必ず書く。
   - [注意] は、ユーザーへのメッセージに含める。
2. **写し**：送る md と成果物を `video-handoff` で番号付きにして、コミット・プッシュする。
3. **送る**：SendUserFile で写しを送る。メッセージには要点だけ（長い md を貼らない）。そのゲートで確定するものと、判断してほしいことを分けて書く。
4. **待つ**：「OK」などの了承をもらうまで、次の工程に進まない。
5. **記録**：結果（了承／作り直し、理由、決まったこと）を status.md の「ゲート記録」と「決定事項」に書き、`いまの工程` を更新してコミット・プッシュする。
6. 作り直しになったら、note-video の「手戻りのルール」で戻り先を決め、やり直す範囲を先に伝える。
