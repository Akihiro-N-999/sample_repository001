# 画像の受け取り

1. `python3 video/lib/intake.py list <アップロードされた ZIP や画像のパス>` を実行する。
2. 出力された一覧画像（contact.png）を Read で見て、指示書（image_prompts.md）のどの画像かを判断する。判断に迷う画像はユーザーに確かめる。
3. `mapping.json` の各項目に `name`（番号なしの保存名。指示書の保存名から `_v1` を外したもの）と `dest`（保存先フォルダ）を書く。使わない画像は `name` を空にする。
4. `python3 video/lib/intake.py apply <mapping.json>` で `名前_v番号` として保存する（作り直しの画像は自動で次の番号）。
5. 確かめる（人にお願いする前に、自分で一覧を見て分かることは指摘する）：
   - 画風が `video/STYLE.md` のコミカル版にそろっているか（アキヒロの基準画像と並べて）
   - スコップの「AI」が崩れていないか、それ以外の文字・ロゴ・看板が入っていないか
   - 緑の背景が均一か（立ち絵）、人物の見た目が指示書どおりか
6. 画風の確認用の1枚目なら、ユーザーに見せて OK をもらってから残りを頼む。それ以外は、品質校閲（一貫性）と内容校閲（文字・既存作品・実在の企業に似ていないか）に回す。
7. 作り直しが要る画像は、指示書の該当する指示文と理由を添えて、ユーザーに頼む。
