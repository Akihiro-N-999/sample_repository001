# ファイルの渡し方

1. `python3 video/lib/handoff.py <渡すファイル…>` を実行する。
   - md は `versions/<名前>_v<番号>.md` の写しになる（最新の写しと同じなら作らない）。
   - 画像・動画・音声は `名前_v<番号>` の写しになる（すでに番号付きならそのまま）。
2. `versions/` の写しを `git add` し、コミット・プッシュする（`video/out/` やリポジトリ外の素材はコミットしない）。
3. 表示された「送るファイル」を SendUserFile で送る。番号付きでないファイルを送らない。
4. リポジトリ外の素材（顔の画像、基準画像など）を渡したときは、「このクラウド環境は一時的なので手元に保存してほしい」と添える。
