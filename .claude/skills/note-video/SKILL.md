# note記事 → 寸劇アニメ動画（オーケストレーター手順）

あなた（本体）はオーケストレーターとして、工程の順番、担当への受け渡し、ユーザーへの確認を受け持つ。制作物の中身は各担当のサブエージェントに作らせ、本体で書き直さない。

## チーム

| 役割 | サブエージェント | 書くファイル（`video/episodes/<slug>/`） |
|---|---|---|
| 企画 | `video-planner` | plan.md |
| 台本 | `video-scriptwriter` | script.md |
| キャラクター設定 | `video-character-designer` | characters.md（＋キャラ表画像） |
| 校閲 | `video-reviewer` | review.md |
| アニメーション制作 | `video-animator` | episode.py（＋静止画・MP4） |

各担当への指示には、毎回 `<slug>` のフォルダパス、読むファイル、ユーザーの要望をはっきり書く。サブエージェントは会話の文脈を持たない。

## 工程

### 0. 準備（本体）
- 記事IDから slug を決める（英小文字とハイフン。例：`shovel`）。
- 記事を取得し `article.md` に保存する：
  `curl -s https://note.com/api/v3/notes/<記事ID>` の `data.name`（タイトル）と `data.body`（HTML）を、見出しと段落を残したテキストにする。有料部分がある記事や、作者がユーザー本人でない記事は、作業前にユーザーに確認する。
- VOICEVOX を起動しておく（`video/README.md`）。

### 1. 企画
- `video-planner` を実行。
- **ユーザー確認①**：plan.md の場面構成・尺・トーンを短くまとめて見せ、了承をもらう。直しがあれば企画担当に戻す。

### 2. 台本とキャラクター設定（並行）
- `video-scriptwriter` と `video-character-designer` を同時に起動する（どちらも plan.md だけに依存する）。
- 両方終わったら、話者IDが script.md と characters.md で一致しているか本体で確かめる。ずれていれば台本担当に合わせさせる。

### 3. 校閲（台本・キャラ）
- `video-reviewer` に plan.md / script.md / characters.md を見せる。
- 「必須」の指摘があれば、該当する担当に review.md を渡して直させ、再度校閲する。この往復は最大2回。それでも残る指摘と「未確認」の項目はユーザーに判断を仰ぐ。
- **ユーザー確認②**：台本（台詞の一覧）とキャラ表画像を見せ、了承をもらう。

### 4. アニメーション制作
- `video-animator` を実行。core.py に大きな変更が要ると報告されたら、ユーザーに伝えてから進める。

### 5. 校閲（映像）
- `video-reviewer` に静止画の一覧画像と MP4 を見せる（映像の崩れ、字幕の誤字、クレジット）。
- 必須の指摘はアニメーション制作担当に直させる（最大2回）。

### 6. 納品（本体）
- MP4 をユーザーに送る（SendUserFile）。
- YouTube 用のタイトル案・説明欄（記事リンク、VOICEVOX クレジット、合成音声を使っている旨）を添える。
- `video/episodes/<slug>/` の md と episode.py をコミットしてプッシュする（`video/out/` は含めない）。

## 報告のしかた
- 各工程の終わりに、ユーザーへ1〜2行で進み具合を伝える（例：「企画ができました。8場面・約4分です」）。
- 音声を耳で聞いて確かめていないこと、規約を確認できなかった項目は、そのとおりに伝える。
