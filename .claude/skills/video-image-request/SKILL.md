# 画像の依頼の出し方

ユーザーの指摘：「Gemini の指示書は ZIP（アーカイブ）にするように、と言ったのが抜けている」。指示書の最後に会話全体の ZIP の依頼文はあったが、一部だけ作ってもらうときの依頼文がなかった。そこで、依頼のたびに依頼書をスクリプトで作る。

1. 今回作ってもらう画像の指示文の番号を決める（指示書 `video/episodes/<slug>/image_prompts/*.md` の見出し「### 番号. …」）。画風の確認用の1枚は、それだけで1回の依頼にする。
2. `python3 video/lib/image_request.py video/episodes/<slug> <依頼の名前> <番号…>` を実行する。
   - 依頼書 `image_prompts/requests/<依頼の名前>_v番号.md` ができる。Gemini の会話ごとに、指示文と「この会話の ZIP の依頼文（今回の画像だけ）」が入る。予備の方法も入る。
   - 番号が見つからないと止まる。指示書の書き方（「- 保存名（制作側が付ける）：`名前`」「- 添付：…」「- 指示文：」の後のコードブロック）を確かめる。
3. 依頼書をコミットし、SendUserFile で送る。**指示書（image_prompts/*.md）をそのまま送らない**（フックで止まる。送ってよいのは requests/ の依頼書だけ）。
4. メッセージでは、作る枚数、添付する画像（アキヒロの基準画像 akihiro_base_v2.png）、最後に ZIP の依頼文を貼ってアップロードしてほしいことを伝える。
5. 届いたら `video-intake` で取り込む。
