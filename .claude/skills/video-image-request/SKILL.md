# 画像の依頼の出し方

ユーザーの指示（2026-11-15）：「アーカイブは私が指示するので指示書からは消しておいて」。依頼書・指示書に、Gemini に ZIP を作らせる依頼文や予備の方法を書かない。

1. 今回作ってもらう画像の指示文の番号を決める（指示書 `video/episodes/<slug>/image_prompts/*.md` の見出し「### 番号. …」）。ユーザーは会話ごとに指示書の全部をまとめて作ってくることがあるので、届いた分は次の依頼から外す。
2. `python3 video/lib/image_request.py video/episodes/<slug> <依頼の名前> <番号…>` を実行する。
   - 依頼書 `image_prompts/requests/<依頼の名前>_v番号.md` ができる。Gemini の会話ごとに、指示文と、今回作る画像の保存名（参考）の一覧が入る。Gemini の設定（4 Hydrogen・思考レベル標準）と、基準画像は2〜3案から選ぶことも自動で入る。
   - 番号が見つからないと止まる。指示書の書き方（「- 保存名（制作側が付ける）：`名前`」「- 添付：…」「- 指示文：」の後のコードブロック）を確かめる。
3. 依頼書をコミットし、SendUserFile で送る。**指示書（image_prompts/*.md）をそのまま送らない**（フックで止まる。送ってよいのは requests/ の依頼書だけ）。
4. メッセージでは、作る枚数と添付する画像（アキヒロの基準画像 akihiro_base_v2.png）を伝える。まとめ方・送り方はユーザーに任せる。
5. 届いたら `video-intake` で取り込む。
